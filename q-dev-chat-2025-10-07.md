Това криденшълите с които влизам в cloud.mongoDb ли са?

---

Не, това НЕ са credentials-ите за cloud.mongodb.com.

Това са **database user credentials** които се създават в MongoDB Atlas:

1. **Влез в cloud.mongodb.com** с твоя акаунт
2. **Отиди в Database Access** (лявото меню)
3. **Създай database user** или използвай съществуващ
4. **Username/Password** от там са нужните credentials

**Не** използвай email/password-а за MongoDB Atlas акаунта.

Алтернативно, в MongoDB Atlas:
- **Database** → **Connect** → **Drivers** 
- Копирай connection string-а който вече има правилния формат

Database user е различен от Atlas account user-а за сигурност.

---

Виждам имена на потребителите, но не и пароли

---

Правилно - MongoDB Atlas не показва паролите от съображения за сигурност. Имаш няколко опции:

**Опция 1: Създай нов database user**
- Database Access → Add New Database User
- Избери username/password authentication
- Задай нова парола и я запомни
- Дай readWrite permissions

**Опция 2: Промени паролата на съществуващ user**
- Database Access → Edit user (иконката с молив)
- Edit Password → Auto-generate или задай нова
- Копирай новата парола

**Опция 3: Използвай готов connection string**
- Database → Connect → Drivers
- Копирай connection string-а
- Замени `<password>` с паролата която знаеш

След като имаш username:password, замени в `.env`:
```
MONGODB_URI=mongodb+srv://your_username:your_password@cluster0.ep2da.gcp.mongodb.net/Dragora_Selector
```
